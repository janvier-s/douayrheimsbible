# Original-spelling ODR: gloss notes still in modern spelling

Lettered gloss notes in `static/data/odr-original` whose text was still the modern-spelling note after the
November 2026 repair. All 63 were checked against the Sancta scans (`~/facsimiles/sancta/<book>/<chapter>/<n>.jpg`)
in November 2026, and 57 were transcribed from the 1609 print. Labels split across a note boundary were re-split
(Ps 42:5 m/o, 42:6 p, 43:25 s, 43:26 t (new note), 44:5 n/p, 48:19 c/d, 50:21 k/l, 52:6 c/d, 113:3 c/d/e).

## Left as they are (5), and one removed

- **psalms 42:6 q, 44:5 o, 58:6 e; wisdom 10:4 c**: the 1609 text is the same as the current note
  ("praise him,", "prosecuting,", "and not spare obstinate persecuters.", "Noe."), so nothing to change.
- **wisdom 14:16 g** ("See next note"): one 1609 margin gloss (14:15 f) covers both `::` markers at vv. 15–16.
  The pointer follows the project convention that the modern text also uses.
- **tobias 5:27 c** (was "Angel Guardian."): removed from the original-spelling notes. Sancta, the Salette
  facsimile (p. 997) and Peters all show the marker in v. 27 with no margin gloss, so the text was editorial.
  The modern dataset keeps its note.
