# Wikisource Phase 1 — Reconcile and Conformance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `generate.py` reproduces every committed page of every generated book byte for byte (golden tests enforce it), and the generator and `lint.py` implement the §4.7 Wikisource conformance rules. Pages that can't be generated yet are frozen.

**Architecture:**
- `generate.py` becomes importable (`main(argv)`), reads a small per-book table `books.json` (page range, ornaments flag), and gains the page-only conventions the Gemini-era sweeps added by hand (`{{sc}}`, `{{lang|grc}}`, punctuation spacing) plus the §4.7 footer/`{{nop}}` rules.
- A new `reconcile.py` regenerates a book into a temp dir, classifies every word-level difference against the committed pages, and runs the evidence ladder (`ladder.py`) on letter-shape and spelling conflicts. Readings the committed page has right are written into `odr-original` under the lock and the fidelity guard. Decisions are kept as JSONL, the seed of the Phase 4 ledger.
- Each book is then reconciled in turn: regenerate → copy into `pages/` → golden flag on → manifest `status: "changed"` where the text differs from live.

**Tech Stack:** Python 3 stdlib (scripts run as `python3 -I`), pytest 9, git.

**Spec:** `docs/superpowers/specs/2026-11-20-wikisource-pipeline-refactor-design.md` (§4.1, §4.2 override rules, §4.6, §4.7, §5 phase 1, §8). Handoff: `docs/superpowers/handoffs/2026-11-20-wikisource-phase1.md`.

## Global Constraints

- The print wins: never modernise ſ, vv, u/v, macrons, ligatures, italics or small caps. The only removals: the † after `{{verse}}` and printer's signature marks.
- Scripts run as `python3 -I`; imports via `sys.path.insert(0, str(Path(__file__).parent))`. Stdlib only.
- All text NFC. Data JSON written only through `jsonfmt.write_like()`, inside the `.git/odr-data.lock` mkdir lock (`git rev-parse --git-common-dir` locates `.git` in this worktree).
- `pages/*.wiki` are written only by `reconcile.py write` (generated books) or by hand edits to frozen pages. No sweep scripts.
- Committing page changes that shift or lose features needs `lint.py … --allow-shift|--allow-loss FEATURE:SCOPE --reason "…"`, and the reason goes in the commit message.
- Scan crops are the last rung: report the unresolved count to the owner and **stop** before reading any image.
- Ornaments off by default (`books.json` `"ornaments": false` for every book).
- No posting, no Wikisource writes, no push, no merge, no edits in `../douayrheimsbible`. Read-only API fetches are paced (≥3 s apart).
- `LIVE_BASE = '494f0400'`: the commit whose pages equal live (audit 2026-11-20). Status "changed" means `wikipost.norm(text) != wikipost.norm(text at LIVE_BASE)`.
- Before each commit: `python3 -m pytest scripts/wikisource/tests -q` passes; `python3 -I scripts/wikisource/lint.py wikisource/1582-rhemes-nt/pages --quiet` reports `0 error(s)`. The one exception: from Task 4 until Task 14, the new §4.7 error codes (`E-hw-title`, `E-status`, `E-tpl-italic`, `E-foot-ital`) may remain on pages that are not reconciled yet. Each commit message lists their count, and the count must never rise.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A catchword with markup (`''6. It is''`, `{{sc|the}}`, `† I`, `CHAP. II.`) must arrive whole and italic-balanced in `{{continues|…}}`, with no `{{rh}}` footer left. → Task 3, `test_footer_markup_catchwords`.
2. `{{nop}}` only where the next page really opens a paragraph (heading, chapter, new paragraph), never mid-paragraph and never on a book's last page. → Task 3, `test_nop_only_on_paragraph_end`.
3. A conflict whose context occurs twice (or not at all) in the data or the XML is reported unresolved and never guessed or written. → Task 6, `test_ambiguous_context_unresolved`, `test_adopt_refuses_non_unique`.
4. `reconcile.py write` never touches a frozen page or a page outside the book's range, even when the generator emits extra pages (Matthew emits 114-115). → Task 2, `test_write_respects_range_and_frozen`.
5. A data write that drops a feature (`Paſſion`→`Paſsion` is an `ls` shift) is refused without `--allow-shift ls:<book> --reason`. → Task 6, `test_adopt_guards_fidelity`.

### Task 2: `reconcile.py` — diff, classify, write

**Files:**
- Create: `scripts/wikisource/reconcile.py`
- Test: `scripts/wikisource/tests/test_reconcile.py`

**Interfaces:**
- Consumes: `generate.main`, `generate.load_books`, `wikipost.norm`, `jsonfmt.write_like`.
- Produces:
  - `generate_book(book: str, out: Path, ornaments: bool | None = None) -> Path`: runs `generate.py` as a subprocess with `python3 -I`, using the `first`/`last` values from `books.json`.
  - `Diff = NamedTuple(page: int, committed: str, generated: str, cls: str)`, where `cls` is one of `'ls:ss'`, `'ls:other'`, `'sc'`, `'greek'`, `'macron'`, `'space'`, `'hw'`, `'head'`, `'foot'`, `'ornament'`, `'text'`.
  - `word_diffs(committed: str, generated: str, page: int) -> list[Diff]`: `difflib.SequenceMatcher(autojunk=False)` on whitespace tokens, one `Diff` per non-equal opcode, classified by `classify(c, g) -> str`.
    - `ls:*` when the two sides are equal after `{{ls}}`→`s`: `ls:ss` when one side has `{{ls}}{{ls}}` and the other `{{ls}}s`.
    - `macron` when they are equal after NFD and stripping U+0304/U+0303 and expanding `ā→an`, `ē→en`, `ō→on`, `ū→un` style titlos (either side).
    - `space` when they are equal after removing whitespace.
    - `ornament` when either side has `image=` or `[[File:`.
    - `head`/`foot` when the diff is inside the first/last `<noinclude>`.
    - Otherwise the first matching marker: `{{sc` → `sc`, `{{lang|grc` → `greek`, `{{hw` → `hw`, else `text`.
  - `write_pages(book: str, gen: Path, pages: Path, manifest: dict) -> list[int]`: copies the generated `first..last` pages that differ into `pages/`. It never writes a page whose manifest entry has `source == 'frozen'`, or any page outside the range. Returns the written pages.
  - `mark_status(pages: Path, manifest: dict, base: str = LIVE_BASE) -> dict[int, str]`: sets `status` to `'changed'` or `'posted'` by comparing `wikipost.norm` with `git show {base}:<path>`. It leaves `source` alone and returns the changes.
  - CLI:
    - `python3 -I scripts/wikisource/reconcile.py diff BOOK [--jsonl OUT]` prints one line per class with its count, then the identical/total pages. With `--jsonl` it also writes every `Diff`.
    - `… write BOOK` regenerates the book and copies the pages.
    - `… status [--write]` prints the changed pages. With `--write` it saves the manifest via `write_like`, recording page 266's revid as 16475295.
